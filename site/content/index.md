# ShaderPlayer Documentation

This site documents ShaderPlayer, the real-time HLSL shader video player for
Windows 11.

Two document sets live here: a manual covering installation, the interface,
and every workflow from opening a video to recording output, and a shader
reference covering the cbuffer contract, the ISF parameter system, and every
shipped shader with its full parameter table.
